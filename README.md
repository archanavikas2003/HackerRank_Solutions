# HackerRank Solutions

My HackerRank solutions for coding practice, problem-solving, and interview preparation.

## About

This repository contains my solutions to [HackerRank](https://www.hackerrank.com/) challenges, organized as I work through different problems and domains. Each solution lives in its own file, named after the challenge it solves.

## Usage

Each file can be run independently:

```bash
python <filename>.py
```

Most solutions read input from stdin, matching the input format used on HackerRank.
